
# Kai Optimized

Kai Optimized is a Minecraft modpack created by me, **Misticalkai**, for everyone to use! I wanted to put together the mods I use along with a custom PvP texture pack to make playing Minecraft a smoother and more enjoyable experience.

The modpack focuses on performance, PvP, and everyday gameplay, bringing together a few useful mods and a custom texture pack called **Misticalpack**.

## Features

- **Performance:** Includes Sodium to help improve Minecraft's rendering performance.
- **PvP Texture Pack:** Comes with Misticalpack, a custom PvP texture pack made for this modpack.
- **Zoom:** Includes a zoom mod for getting a closer look at things in-game.
- **Online Play:** Includes Essentials for playing online with friends.
- **Convenience:** Brings these features together in one modpack, so you don't have to set everything up separately.

## Supported Versions & Roadmap

I'm bringing Kai Optimized back after being archived for a while! One of my goals is to expand Minecraft version support and make the modpack available across more releases.

There's a lot of work involved in updating mods, checking compatibility, and making sure everything works properly, so I'm working through the versions in stages.

You can track updates [here](https://github.com/Misticalkai-Studios/kai-optimized/issues/1).
